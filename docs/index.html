Installer POCL sur une carte, depuis le navigateur

Branche la carte en USB et clique sur Installer POCL : la page reconnaît toute seule la carte (Wemos D1 mini, ESP32, ESP32-C3 Super Mini ou ESP32-S2 Mini) et y copie la dernière version du firmware. Rien à installer sur l'ordinateur.

Il faut Google Chrome ou Microsoft Edge sur un ordinateur, et un câble USB qui transmet les données.

Ce navigateur ne sait pas dialoguer avec une carte USB (Web Serial). Ouvre cette page dans Google Chrome ou Microsoft Edge sur un ordinateur.

La page doit être ouverte en https:// pour accéder au port USB.

L'outil de flash n'a pas pu être chargé (site unpkg.com injoignable). Vérifie la connexion à Internet puis recharge la page.

 

1Choisis ta carte et prépare-la

Clique sur ta carte pour voir comment la préparer.

2Clique sur « Installer POCL »

Les fenêtres de l'outil de flash sont en anglais ; voici ce qu'elles veulent dire.

  1. Le navigateur affiche la liste des ports USB : choisis celui de la carte, puis Connexion. Si tu hésites, débranche la carte : le port qui disparaît de la liste est le sien.
  2. Install POCL lance l'installation. Logs & Console affiche ce que la carte écrit (le moniteur série).
  3. Erase device : laisse la case décochée pour garder la configuration et le WiFi déjà enregistrés sur l'objet. Coche-la pour tout effacer, par exemple si la carte contenait un autre programme. Puis Next.
  4. Install confirme. Ne débranche pas la carte pendant Installing (une à deux minutes) et garde la page visible.
  5. Installation complete! : c'est fini. Next puis ferme la fenêtre.

3Connecte l'objet au WiFi

  1. Avec un téléphone ou un ordinateur, connecte-toi au réseau WiFi POCL-XXXX créé par l'objet.
  2. Ouvre http://192.168.4.1 dans le navigateur.
  3. Dans l'onglet 📶 Réglages, choisis le WiFi de la maison ou de l'atelier et saisis son mot de passe. Ensuite, la page de l'objet est à l'adresse http://pocl-xxxx.local.

Le mode d'emploi complet (données ouvertes, servos, LED, écrans…) est dans le README du projet.

🔧 Ça ne marche pas ?

La carte n'apparaît pas dans la liste des ports

Essaie un autre câble : beaucoup de câbles USB, surtout en USB-C, ne transmettent que le courant. Branche la carte directement sur l'ordinateur, sans hub.

Windows ou macOS : la Wemos D1 mini et beaucoup d'ESP32 ont une puce USB CH340 ou CP2102 qui demande parfois un pilote (CH340, CP2102).

Linux : ton compte doit avoir le droit d'utiliser les ports série : sudo usermod -aG dialout $USER, puis ferme et rouvre ta session. Avec Chromium installé en snap : sudo snap connect chromium:raw-usb.

ESP32-C3 et ESP32-S2 : mets la carte en mode téléchargement (étape 1) ; un nouveau port apparaît alors.

« Failed to connect », « Failed to initialize » ou rien ne se passe sur « Connecting »

La carte n'est pas passée en mode téléchargement. Ferme la fenêtre, mets la carte en mode téléchargement à la main (BOOT ou 0 maintenu, appui sur RESET ou RST, relâche), puis clique à nouveau sur Installer POCL.

Le port est peut-être déjà ouvert par un autre programme : ferme le moniteur série (flash.sh --monitor, IDE Arduino) et les autres onglets qui utilisent la carte.

ESP32-S2 Mini : erreur ou « Disconnected » à la fin

Si la barre d'installation est allée jusqu'au bout, le firmware est bien installé : une S2 Mini mise en mode téléchargement avec son bouton ne peut pas toujours être redémarrée par l'USB. Appuie sur RST : POCL démarre.

L'objet a perdu sa configuration

La case Erase device était cochée : tout a été effacé. Si tu avais exporté une recette (Réglages › Recettes), importe-la de nouveau.

📦 Mettre à jour sans câble, ou flasher autrement

Un objet déjà connecté au WiFi se met à jour depuis sa propre page : 📶 Réglages › Mise à jour du firmware, avec le fichier de mise à jour de sa carte. Les fichiers complets servent à esptool (adresse 0x0) ou à ./flash.sh --bin.
